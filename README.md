# Sigma Academie — site vitrine

Landing page moderne (esprit xPage) pour le centre **Sigma Academie**.

## Ouvrir en local
Ouvrez `index.html` dans le navigateur, ou servez le dossier :

```bash
cd sigma-academie
python3 -m http.server 8080
```

Puis allez sur `http://localhost:8080`.

## Publier sur Hostinger
Uploadez tout le contenu du dossier dans `public_html` (ou un sous-dossier / sous-domaine).

## À personnaliser avant mise en ligne
- Téléphone et adresse (section Contact)
- Brancher le formulaire sur WhatsApp / email / CRM
- Remplacer les textes si besoin (FR/AR dans `js/app.js`)
